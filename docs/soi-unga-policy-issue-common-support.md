# UNGA policy-code common-support audit

The official SWP/GESIS issue taxonomy provides 30 observed policy codes. A diagnostic threshold of at least **five distinct resolutions in every calendar year** identifies six codes: **102, 110, 111, 112, 118, 129**. A threshold of three identifies eleven. Both thresholds are exploratory, not preregistered or sufficient for causal influence claims.

The 19 resolutions without any 100–134 policy code are enumerated in the JSON output; they remain part of the existing unadjusted 358-resolution baseline, but cannot be assigned an issue code without an authoritative source.

A six-code restricted panel may be useful as a separately labeled **common-support sensitivity**, but it does **not** represent the entire UNGA agenda. Before publication, verify official code labels, actor-year matched-vote counts, pooled topic weights and uncertainty by resolution, and sensitivity to abstention and inclusion rules. No topic-adjusted or influence score is authorized.
