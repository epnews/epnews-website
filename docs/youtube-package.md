# EP News YouTube package

After live article verification, prepare a fact-checked hook, development, impact and CTA, approved image, title, description with canonical URL, and tags. Use the Contradiction Angle only when supported; the current renderer is a contradiction prototype. For other stories adapt the scene label before rendering. Install Pillow, FFmpeg and DejaVu Sans Bold on Linux. Run `python scripts/ep_shorts.py config.json output.mp4` with JSON keys image, hook, development, impact, cta (optional crop). Output is 1080x1920, 30fps, 15s, H.264 Main/yuv420p, AAC silence, faststart. Inspect all scenes, safe areas, factual accuracy, provenance and disclosure; verify full decode and dimensions. Use only rights-cleared audio. Transfer graphics through the established Drive policy. Create Metricool YouTube draft only (draft=true, autoPublish=false, private, notifySubscribers=false), News & Politics, not made for kids for ordinary general-audience news; disclose realistic synthetic content when applicable. Obtain explicit approval before scheduling or publishing. Actual automatic publication remains untested. No website runtime or Facebook changes. Do not commit videos or secrets.

## Mandatory encoding gate
Use H.264 Main level 4.1 avc1, yuv420p, 1080x1920, 30 fps, AAC-LC stereo 44100 Hz mp4a, faststart, 15 seconds. Run `python scripts/validate_ep_short.py output.mp4` before every handoff, even for alternate renderers. Reject any mismatch; full decode alone is insufficient. User confirmed playback of corrected Russia Short; exact cause not isolated. CI smoke test renders a fixture and rejects a 48 kHz variant. No publication without approval.
