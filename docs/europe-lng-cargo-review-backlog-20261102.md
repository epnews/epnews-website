# Europe LNG cargo review backlog

This summarizes six previously introduced gates into a **human-review queue**: evidence-field completeness, terminal/vessel source-type independence, upstream provenance differentiation, chronological/unit plausibility, IMO checksum and vessel-identity consistency. A missing gate is a blocker, never an assumed pass. The script consumes an already enriched case file; it does **not** run or join upstream scripts and does not retrieve new external evidence.

Even a fully passing case is only eligible for manual review. A reviewer must still authenticate terminal records, vessel movement, cargo volumes, loading/transshipment and independent upstream sources. No physical-origin or geopolitical influence claims follow from these gates. No meter changes or score updates (20/30 evidence audit; 53% readiness).
