# Secure Canva import

Use a fresh full-size PNG export URL, not a thumbnail or editor link. Store it in the repository Actions secret `EP_CANVA_EXPORT_URL`; never commit signed URLs. Run Secure Canva image import on a feature branch with the slug and blank hash. Inspect the staged artifact visually and confirm photo provenance and approval. Copy the SHA-256 from receipt.json and rerun with that hash while the URL is valid. The workflow commits exact bytes and manifest together, without publishing. Then complete article registration, editorial evidence and branch preflight as usual. Delete the temporary secret after use. Existing Drive imports remain supported. Only the Canva export host is allowed; redirects are blocked. A failed or expired URL must be replaced with a fresh full-size export. The first run is staging only.
