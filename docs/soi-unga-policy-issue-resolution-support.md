# Source-defined policy-code resolution support (2021–2024)

After excluding non-issue regional, country and nonanalytic codes, the original SWP/GESIS metadata yields **30 distinct issue codes (100–134)**. Of 358 recorded resolutions, **339** have at least one substantive issue code and **19** lack an issue code (2021: 3; 2022: 5; 2023: 4; 2024: 7).

The JSON audit records, for each year and issue code, the number of **distinct resolutions** and the sum of fractional resolution allocations among issue codes. This distinguishes independent resolution coverage from the much larger count of country-vote pairs. Exactly **22** issue codes have at least one resolution in every year; coverage alone is not sufficient support for reliable annual estimates.

A **five-distinct-resolution minimum is shown as an exploratory diagnostic only**, not a validated statistical threshold or authorization for scoring. Before calculating topic-standardized agreement: establish defensible issue grouping from authoritative code definitions, pre-register support thresholds, document issue-less resolution treatment and compare sensitivity. No influence score or needle change.
