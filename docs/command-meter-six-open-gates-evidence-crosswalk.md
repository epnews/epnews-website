## Decision order
1. **Use existing research first.** For each open requirement, evaluate whether a source has already satisfied the exact acceptance test. If not, identify the smallest missing primary record or model input.
2. **Do not falsely close by relabeling.** Observed changes and modeled 2050 scenarios do not establish 2026 shock causation.
3. **Close descriptive measurement separately** from causal influence. EU27 40.58% share is a separately defined observed statistic, not the NUPI EEA 62% share.
4. **Explicit unidentifiability finding** requires a written review of alternative identification designs; it is not an automatic escape hatch for readiness.
5. **Keep the denominator stable** and publish counts of gate statuses alongside editorial readiness when useful.
