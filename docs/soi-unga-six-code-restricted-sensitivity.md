# Six-code restricted UNGA voting sensitivity

A source-defined **restricted sensitivity panel** uses policy issue codes 102, 110, 111, 112, 118 and 129, each observed on at least five distinct resolutions in every year 2021–2024. This threshold was identified exploratorily after reviewing the data; it must not be represented as pre-registered confirmatory inference.

Run the script against the original 69,094-position validated source extract, the 358-resolution topic metadata, and the frozen 160-country cohort. The output reports actual matched country pairs, agreements, eligible resolutions, and a restricted descriptive agreement percentage for each of five spheres by year, plus fractional attribution to the six codes. Missing/non-voting records are excluded; EU proxy requires 20 recorded EU27 member votes and 75% unique majority.

The **restricted aggregate is not a full-agenda topic-adjusted score**. Compare it to the existing full 358-resolution unadjusted baseline, disclose selection effects, validate source issue-code semantics and resolution-level uncertainty. Do not move the main influence needle or label the restricted panel as measured diplomatic influence.
