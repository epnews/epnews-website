# UNGA issue-code missingness: 19-resolution source register

The source metadata includes **19 of 358 recorded resolutions** without any issue code in the 100–134 range (2021: 3; 2022: 5; 2023: 4; 2024: 7). Their observed non-issue labels are preserved verbatim in the accompanying JSON. This is **missing policy classification**, not missing voting data and not proof that a resolution has no policy subject.

The full-agenda descriptive agreement baseline retains these resolutions. Issue-standardized calculations must flag them as unclassified until independent authoritative issue metadata is established. Never substitute regional codes 201–223, country codes 300–547, or 600–605 administrative labels for issue codes. This audit does not change any diplomatic influence score or meter needle.
