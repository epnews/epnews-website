# Standardized UNGA external-partner missing-vote coverage and worst-case bounds

Audited 2021–2024 SWP/GESIS country-position archive; same 160-country cohort as the preliminary diplomatic display. This report records matched votes, missing partner votes, and conservative identification bounds. For each actor/year: coverage = matched / (matched + missing); lower = agreements / (matched + missing); upper = (agreements + missing) / (matched + missing). These bounds make **no assumptions** about how absent countries would have voted. They are not statistical confidence intervals, and their endpoints should not be treated as measured voting behavior.

The companion JSON includes 20 actor-year observations with original numerator, denominator, missing counts, coverage and bounds. Coverage is approximately 89–92% across the observed period. This establishes a transparent missingness audit, **not** a complete issue-mix adjustment or geopolitical influence validation. No main needle authorization.
