**Research reuse rule:** For any new article, follow the article's cited dataset, compare its date/definition/period against this register and existing repository evidence, and only add a new row when it closes a missing measurement or materially changes uncertainty. Repeating the same DOE price estimate in multiple articles does not count as multiple independent observations.

**Next falsifiable test:** Construct a matched monthly 2026 price/supply/weather/storage panel with a documented pre-shock forecast baseline, identify export-caused marginal demand, and report uncertainty. Until then keep readiness at 53%.
