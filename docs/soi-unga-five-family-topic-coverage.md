# Exploratory five-family topic grouping — coverage only

The original 60 `main_category` codes are numerically grouped by their **first digit** into five families: 1, 2, 3, 4 and 6. This is a reproducible numerical aggregation, **not yet a verified semantic taxonomy**. Some resolutions carry multiple codes; fractional attribution uses one equal share per distinct family to avoid double-counting.

Every family has at least one resolution in each year 2021–2024. However, family **3** has extremely sparse support (only a small fractional-resolution weight in each year). This **does not establish sufficient actor-partner matched vote counts** or validate thematic comparability. Before using adjusted figures: verify the authoritative meanings of the category families, independently count valid matched pairs by actor/year/family, specify minimum support thresholds, and run alternative grouping sensitivity.

The 60-code full-topic-adjustment gate remains failed. Do not publish five-family adjusted percentages or move the influence needle based on this exploratory grouping.
