# Social duplicate gate
Before rendering or creating any draft, obtain fresh, complete provider history for the connected channel, including existing drafts, scheduled posts, private uploads and published posts. Normalize to JSON {network,checked_at,complete,posts:[{id,status,slug,article_url,text,description,publicUrl}]}. Set complete=true only when the provider coverage is actually verified. Run node scripts/check-social-duplicate.mjs SLUG youtube SNAPSHOT.json (or facebook). Any matching post blocks new production; inspect and reuse the existing record. Missing, incomplete or stale history blocks automation. Canonical URL matching is not sufficient for posts lacking article identifiers: also review titles and provider IDs before clearing the gate. Keep snapshots private and out of Git. This is a validator, not a provider integration; no automatic Metricool authentication or publication is implemented. A trusted connector or authenticated runner must supply the snapshot. Never auto-delete or republish existing posts.
