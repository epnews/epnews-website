# Publication state engine — phase 1
Read-only event-driven snapshots and regression tests. Main remains authoritative. Every snapshot re-fetches each PR before classification. Closed/merged overrides stale CI. Exact SHA required. Artifacts are timestamped and retained 30 days. No credentials beyond read-only GITHUB_TOKEN; no merge, code mutation or social posting.
This phase deliberately never emits READY without independent preview evidence. Required branch policy may be unavailable to the token or omit rulesets; do not infer readiness. Publication path detection is only a candidate heuristic, not approval evidence. Existing authenticated handoff remains mandatory.
The existing browser verification workflow remains the deployment verifier; this snapshot does not claim LIVE. The hourly ChatGPT monitor must independently verify approval, policy, preview and browser evidence. Native GitHub workflow results are available; push notification delivery, durable deduplication and joining browser artifacts are not implemented in this phase. Workflow-run events use the main-branch script; PR tests run with read-only permissions. No auto-merge.
